# PS2 Native Recomp Tools

A friendly GUI for converting PlayStation 2 disc images into native PC builds with the ps2-native-recomp toolchain: add an image, convert, and play — with network-share browsing built in.

## Credits

- **ps2-native-recomp** — created by **exoteric33** (MIT License). This GUI is a front end; all conversion credit belongs to the original tool and its author.
- Disc images are the user's own; no game data, BIOS files, or SDK material are included or distributed.

## Notes

Packages (AppImage/ZIP) are attached to this repo's Releases. The GUI never bundles a PS2 BIOS — the toolchain does not need one.
